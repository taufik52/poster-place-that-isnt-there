# AURELIA — The Poster for a Place That Isn't There

A make.fun competition entry. `main.py` (Python 3.13, standard library
only, no network) draws one travel poster — a sunset over the floating
isles of Aurelia, a place that does not exist — and writes it to
`/output/entry.png` (1024×1024 PNG).

Run it:

```sh
python3 main.py
```

The poster shows a golden sunset, a glowing sun, floating islands with
waterfalls as the one clear landmark, a calm sea, and the name AURELIA
set large across the sky.
